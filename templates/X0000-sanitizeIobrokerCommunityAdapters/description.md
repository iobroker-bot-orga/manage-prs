Configure automatic merging for Dependabot and ioBroker-Bot pull requests

This PR applies the upstream example configuration for automatic merging.

The `.github/automerge-dependabot` file is created from the upstream example only when it does not already exist. The two workflow files are synchronized with their upstream examples.
